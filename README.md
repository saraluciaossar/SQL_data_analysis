# SQL Data Analysis - IT Academy
This repository contains SQL projects developed during the IT Academy data analysis specialization, using MySQL.

The work focuses on modeling and analyzing transactional data from CSV datasets, covering the full process from data preparation to query-based analysis.

### Project scope
- Design of a relational database using a star schema
- Data cleaning and preparation from raw CSV files
- Creation of fact and dimension tables
- Implementation of primary and foreign keys
- Analytical queries to extract insights from transactional data

### Key analyses
- Identification of users with high transaction volume
- Average transaction amount per IBAN
- Credit card status based on the last transactions (active vs inactive)
- Product-level aggregation using normalized transaction data

### Skills
- SQL querying (JOIN, subqueries, CTEs, window functions, views, case)
- Aggregations and grouping
- Data modeling (star schema)
- Data cleaning and transformation
- Analytical thinking applied to structured data
